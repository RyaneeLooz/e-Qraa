# e-Qraa 🎓
> La première plateforme éducative algérienne basée sur une économie de Coins.

## 🌟 Présentation
e-Qraa est une marketplace éducative premium conçue pour mettre en relation étudiants et formateurs en Algérie. 
Le projet utilise un modèle économique unique basé sur des **e-Qraa Coins** (jaunes 🟡), avec un système de commission de 20% pour la plateforme.

## 📁 Structure du projet
- `/frontend` : L'interface utilisateur complète (React + Tailwind CSS).
- `/backend` : (À venir) API REST et Base de données.
- `eqraa_tasks_frontend.json` : Suivi des tâches frontend.
- `eqraa_tasks_backend.json` : **Guide complet pour le développeur backend.**

## 🛠 Tech Stack (Frontend)
- **Framework** : React 19 + Vite 8
- **Styling** : Tailwind CSS v4
- **State** : React Context API
- **Icons** : Emojis & SVG personnalisés

## 🚀 Installation & Lancement (Frontend)
1. Cloner le repo.
2. `cd frontend`
3. `npm install`
4. `npm run dev`

## 🔑 Identifiants de Test (Données Mock)
- **Admin** : `admin@e-qraa.dz` (Donne accès au panel ⚙️ Admin).
- **Prof** : Tout email + rôle "Formateur" à l'inscription.
- **Étudiant** : Tout email + rôle "Étudiant" à l'inscription.
